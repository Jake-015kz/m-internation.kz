# Certificates Section Redesign — Вариант 1

## Концепция
Бегущая строка (marquee) с сертификатами + крупный фоновый текст "CERTIFIED"

## Структура компонента

```
CertificatesSection
├── Background Text (крупный "CERTIFIED" на фоне)
├── Marquee Row 1 (сертификаты вправо)
├── Marquee Row 2 (сертификаты влево)
└── Header (заголовок и описание)
```

## Дизайн

### Фоновый текст
- Крупный текст "CERTIFIED" по центру секции
- Размер: 8-12rem (адаптивный)
- Цвет: полупрозрачный (opacity: 0.05-0.1)
- Шрифт: monospace, bold
- Позиция: absolute, centered

### Бегущая строка (Marquee)
- Две строки с сертификатами
- Строка 1: движение вправо
- Строка 2: движение влево
- Элементы: название сертификата + иконка
- Скорость: медленная, плавная
- Бесконечная анимация

### Карточки сертификатов в строке
- Компактные карточки с названием
- Фон: glassmorphism (полупрозрачный)
- Рамка: тонкая, при наведении подсветка
- Иконка слева, название справа

## Анимации
- Marquee: CSS animation infinite scroll
- Background text: появление при скролле (fade in)
- Карточки: hover effect (scale + glow)

## Адаптивность
- Мобильные: одна строка, медленнее
- Планшет: две строки
- Десктоп: две строки, быстрее

## Цвета
- Основной: lime (#B4E632)
- Фон: прозрачный / glass
- Текст: white / muted
