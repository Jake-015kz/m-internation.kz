## Фаза 2: Анимационная система

### 2.1 GSAP ScrollTrigger — архитектура

```
┌─────────────────────────────────────────────────────────┐
│                  SCROLL-DRIVEN LAYERS                   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Layer 1: HERO                                          │
│  ├── Pin hero section                                   │
│  ├── Fade out content as user scrolls                   │
│  └── Product image parallax (scale + y)                 │
│                                                         │
│  Layer 2: CERTIFICATES                                  │
│  ├── Pin section                                        │
│  ├── Horizontal scroll of certificates                  │
│  └── Progress indicator                                 │
│                                                         │
│  Layer 3: PRODUCTS                                      │
│  ├── Pin section                                        │
│  ├── Horizontal pan (vertical scroll → horizontal)      │
│  └── Each product gets full viewport                    │
│                                                         │
│  Layer 4: ABOUT                                         │
│  ├── Standard scroll                                   │
│  ├── Timeline items reveal alternately                   │
│  └── Year counter animation                             │
│                                                         │
│  Layer 5: BUSINESS                                      │
│  ├── Sticky-stack cards                                 │
│  └── Each card pins, previous scales down               │
│                                                         │
│  Layer 6: CTA                                           │
│  ├── Split-screen reveal                                │
│  └── Text + image from opposite directions              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.2 Кастомный курсор

```
- Замена cursor-glow на полноценный кастомный курсор
- Внешний круг (32px) + внутренняя точка (6px)
- На hover на интерактивные элементы — круг расширяется (48px)
- На тексте — становится вертикальной линией (text selection style)
- На изображениях — превращается в "View" label
- Плавное следование за мышью (lerp, не мгновенное)
- Скрыт на мобильных (touch devices)
- Уважает prefers-reduced-motion
```

### 2.3 Микроинтеракции

```
Кнопки:
  - Magnetic pull к курсору (GSAP, не React state)
  - Нажатие: scale(0.97) + лёгкий ripple
  - Hover: фоновый градиент появляется со стороны курсора

Карточки:
  - 3D tilt (perspective: 1000px, rotateX/Y по позиции мыши)
  - Блик на поверхности (gradient overlay, следует за мышью)
  - Hover: мягкий lift + shadow increase

Ссылки:
  - Underline рисуется слева направо при hover
  - Текст слегда сдвигается вправо (2px)

Изображения продуктов:
  - Parallax внутри контейнера при движении мыши
  - Масштаб 1.0 → 1.05 при hover
```

### 2.4 Переходы между секциями

```
- Каждая секция имеет уникальный reveal-паттерн:
  Hero:        letter-by-letter text reveal + image slide-up
  Certificates: clip-path reveal (снизу вверх)
  Products:    horizontal pan (scroll-hijack)
  About:       alternate left/right fade-in для timeline
  Business:    sticky-stack с scale/opacity
  CTA:         split reveal (текст слева, визуал справа)

- Между секциями: тонкая линия-разделитель, рисующаяся при скролле
- Фон секций: чередование основного и приподнятого фона
```

## Фаза 4: Двухцветная тема

### 4.1 Светлая тема (по умолчанию)

```
- Фон: тёплый белый (не чистый #fff)
- Текст: глубокий графит (не чёрный)
- Акцент: глубокий изумруд
- Карточки: белые с тонкой границей
- Тени: мягкие, с тёплым оттеноком
- Шум: очень тонкий (opacity 0.015)
```

### 4.2 Тёмная тема

```
- Фон: глубокий графит (не чёрный)
- Текст: мягкий белый
- Акцент: яркий изумруд (ярче чем в светлой)
- Карточки: приподнятый фон с границей
- Тени: глубокие, чёрные
- Шум: не нужен (и так есть глубина)
```

### 4.3 Переключатель темы

```
- Анимация: плавный переход всех цветов (600ms, spring easing)
- Иконка: Sun/Moon с анимацией вращения
- Позиция: в header, рядом с language switcher
- По умолчанию: светлая тема (prefers-color-scheme: light)
- Сохранение: localStorage
```

## Фаза 5: Финальная проверка

### 5.1 Accessibility

```
- [ ] Контраст текста ≥ 4.5:1 (AA) для body, ≥ 3:1 для large
- [ ] Все интерактивные элементы ≥ 44×44px
- [ ] Focus states видимы на всех элементах
- [ ] prefers-reduced-motion: все анимации отключены
- [ ] Семантический HTML: header, nav, main, section, footer

- [ ] Alt text на всех изображениях
- [ ] Keyboard navigation работает полностью
```

### 5.2 Performance

```
- [ ] LCP < 2.5s (hero image priority + preload)
- [ ] CLS < 0.1 (reserved space for images, fonts)
- [ ] INP < 200ms (GSAP вне main thread)
- [ ] Lazy load для below-fold секций
- [ ] Font display: swap
- [ ] will-change только на анимируемых элементах
```

### 5.3 Responsive

```
- [ ] Mobile (375px): все секции читаемы
- [ ] Tablet (768px): grid адаптируется
- [ ] Desktop (1024px): полный layout
- [ ] Large (1440px+): max-width контейнера
- [ ] Landscape mobile: корректные высоты
- [ ] Горизонтальный scroll отсутствует
```

### 5.4 Cross-browser

```
- [ ] Chrome, Firefox, Safari, Edge
- [ ] backdrop-filter с fallback
- [ ] CSS @supports для новых свойств
- [ ] Touch devices: кастомный курсор скрыт
```
