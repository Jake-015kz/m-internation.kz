# About Section Redesign — Timeline

## Концепция
Вертикальная временная шкала с историей компании M-International

## Структура компонента

```
AboutSection
├── Header (заголовок "О компании")
├── Timeline
│   ├── TimelineItem 1 (2018 — Основание)
│   ├── TimelineItem 2 (2019 — Первые продукты)
│   ├── TimelineItem 3 (2020 — Международная экспансия)
│   ├── TimelineItem 4 (2022 — Сертификаты качества)
│   └── TimelineItem 5 (2024 — Сегодня)
└── CTA (ссылка на страницу "О компании")
```

## Дизайн

### Временная шкала
- Вертикальная линия по центру (на десктопе)
- Точки на линии для каждого события
- Карточки событий чередуются: слева, справа
- На мобильных: все карточки справа от линии

### Карточки событий
- Год (крупный, зелёный)
- Заголовок события
- Краткое описание
- Иконка (опционально)
- Анимация появления при скролле

### Линия времени
- Цвет: lime (#B4E632)
- Толщина: 2px
- Точки: 12px диаметр
- Анимация заполнения при скролле

## Анимации
- Появление карточек при скролле (fade in + slide)
- Подсветка активной точки на линии
- Hover-эффект на карточках (scale + glow)

## Адаптивность
- Мобильные: одна колонка, линия слева
- Планшет: одна колонка
- Десктоп: две колонки с чередованием

## Цвета
- Основной: lime (#B4E632)
- Фон карточек: glassmorphism
- Текст: white / muted
- Линия: lime с градиентом
